# 🎓 学位英语备考助手

面向**四川师范大学学位英语考试**的一站式备考 Web 应用（PWA）。零基础友好：内置大纲高频词、中文语法讲义、原创题库、全真模拟卷，支持离线使用、可安装到手机/电脑。

## ✨ 功能一览

| 模块 | 说明 |
|---|---|
| 📚 背单词 | 1604 个核心高频词（音标/释义/例句/朗读），闪卡 + 自测双模式，间隔重复（SRS）记忆 |
| 📖 语法 | 13 节零基础中文讲义（时态、非谓语、从句、虚拟语气…），每节含随堂小测 |
| ✏️ 专项练习 | 615+ 原创题目：词汇语法 250 / 阅读 25篇×5题 / 完形 10篇×10空 / 英译汉 60 / 汉译英 60 / 作文模板 20，即时解析 |
| 📝 模拟考试 | 5 套全真卷（120 分钟计时、自动评分、分节报告），题型分值可按学校通知调整 |
| 🎯 错题本 | 自动收录答错题目，支持重练与查看解析 |
| 🗓️ 学习计划 | 输入考试日期自动生成每日任务（新词/语法/专项/模拟），支持打卡与冲刺模式 |
| ⚙️ 设置 | 数据导出/导入备份、**局域网双向同步**、考试日期、每日词量目标 |

## 🚀 快速开始

```bash
npm install        # 安装依赖
npm run dev        # 本地开发（http://localhost:5173）
npm run build      # 生产构建（输出 dist/）
npm run preview    # 预览生产构建（http://localhost:4173）
npm test           # 运行单元测试（28 项：SRS/计划/评分/内容库）
```

## 📱 安装为 APP（离线使用）

- **手机（推荐）**：用浏览器打开部署后的网址 → 浏览器菜单「添加到主屏幕 / 安装应用」→ 之后可从桌面图标直接打开，离线可背单词刷题。
- **电脑**：Chrome/Edge 地址栏右侧出现安装图标 → 点击安装，或菜单「安装应用」。

## 🌐 局域网同步（手机 ↔ 电脑学习记录自动互通）

1. 电脑双击 **启动学习助手.bat**（会自动构建并启动服务器，**保持窗口不要关**）。
2. 双击 **查看手机访问地址.bat**，记下地址（形如 `http://192.168.1.5:4173`）。
3. 手机连**同一个 Wi-Fi**，浏览器打开该地址 → 在「设置 → 局域网同步」确认显示「已连接」。
4. 之后两端学习记录**自动双向同步**（打开页面时、恢复联网时、每 5 分钟各一次），按「记录最后修改时间最新者胜」合并，互不覆盖。

> 同步服务器就是电脑上的 `server.mjs`（随 bat 启动），学习记录会保存到电脑磁盘的 `data/sync-data.json`，关掉浏览器也不会丢。
> 设置页还提供「立即同步」「用电脑数据覆盖本机」「用本机覆盖电脑」三个手动按钮。
> GitHub Pages 等静态托管**没有**此功能（无服务器），仍可手动「导出/导入备份」。

## 🌐 部署（免费静态托管）

数据全部存储在浏览器本地（IndexedDB），无需服务器，任选一种：

1. **GitHub Pages（首选）**
   ```bash
   npm run build
   npx gh-pages -d dist
   ```
2. **Vercel / Netlify**：导入本仓库，构建命令 `npm run build`，输出目录 `dist`。
3. **局域网自用（推荐，支持手机同步）**：双击 `启动学习助手.bat`，手机连同一 Wi-Fi 访问电脑 IP:4173，学习记录自动双向同步。
4. **Gitee Pages**：上传 `dist` 目录到 Gitee 仓库并开启 Pages 服务。

> ⚠️ 换设备或清除浏览器数据前，请先在「设置 → 数据备份」导出 JSON；换设备后导入即可恢复进度。使用「启动学习助手.bat」的局域网模式时，学习记录会自动双向同步，无需手动备份。

## 🧭 使用建议（2-3 个月冲刺）

1. **第 1 天**：设置 → 填考试日期 → 学习计划 → 生成计划。
2. **每天**：按首页「今日任务」执行 → 背新词（闪卡→自测）→ 复习到期词 → 做 1 组专项。
3. **每周**：完成 1 套模拟卷，看分节报告，针对薄弱题型（首页会提示）重点练习。
4. **考前 2 周**：学习计划切「冲刺」模式 → 只刷高频词 + 错题本 + 作文模板 + 模拟卷。

## 🛠 技术栈

Vite 8 · React 18 · TypeScript · Tailwind CSS v4 · Zustand · IndexedDB (idb) · vite-plugin-pwa · Node 内置服务器（server.mjs，局域网同步）

## 📁 目录结构

```
src/
├─ pages/        # 首页/背单词/语法/专项/模拟考/错题本/计划/设置
├─ data/         # 内置内容（words/ grammar/ questions/ mock）
├─ store/        # Zustand 状态（单词SRS/作答/计划/设置）
├─ db/           # IndexedDB 封装
├─ lib/          # SRS 引擎、计划生成器、评分器
└─ components/   # 通用组件
tests/           # 单元测试
```
